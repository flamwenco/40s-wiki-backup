# Pragma
Pragma is a WKL 40% minivan style keyboard created by dingusxmcgee. It utilizes a 'perimeter oring mount' designed by dingus and utilized the Omnibus PCB. It features a tasteful front lip, low front height, subtle undercut curved side profile, and a shadow line running along the entire outside edge.

## Availability

### Open Source

The case files are open sourced under the UNLICENSE license. The Github repository is [here](https://github.com/dingusxmcgee/Pragma). 

### Private Buys

There were 2 small prototype runs in 2023 by dingus of 2 cases each. There were no plans for a larger run, and the case was open sourced in order to benefit the community.
