# odmuG
odmuG is a minor spin on the board, Gumbo, created by rain, which is a 40% minivan variant using a single piece case and oring gummy mount. How is it different? Dingus added a jst channel, made it WKL and put a smile on the shrimp. Gumbo was never released(i think?), neither was odmuG. It uses a Gumbo pcb, by Rain.

odmuG is Gumbo backwards.
